# Flask Portfolio

My first Python web app, built with Flask. This project is part of my college portfolio.

## What it does
A simple Flask web application with multiple pages, HTML templates, and custom CSS styling.

## Built with
- Python
- Flask
- HTML/CSS (Jinja2 templates)

## How to run it
1. Clone this repo
2. Create a virtual environment: `python -m venv venv`
3. Activate it: `.\venv\Scripts\Activate.ps1` (Windows)
4. Install dependencies: `pip install flask`
5. Run the app: `python app.py`
6. Open `http://127.0.0.1:5000` in your browser

How to push changes to a github repo, basic flask usage.
